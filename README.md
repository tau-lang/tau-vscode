# Tau

Tau is a new and experimental language. The language is still unstable and in active development. You can find it the compiler on [Codeberg](https://codeberg.org/tau-lang/tau) or [GitHub](https://github.com/tau-lang/tau) (mirror and bug report only).

## Features

- Syntax highlighting
- Snippets

## Known Issues

- Types and variable names are only detected based on naming conventions
- Unstable features like the "import" keyword, member functions or module paths are not yet supported
